## Code for manuscript: 2026-Juan Li, Joachim Hermisson and Himani Sachdeva-Eﬀect of population structure and stabilizing selection on quantitative genetic variation

This project code consists of three main components: analytical computations, simulations, and figure generation. 

### Analytical computations.

The mathematic notebook **2026-StabSel.nb** contains numerical evaluations of analytical expressions derived in the manuscript. Results from this notebook were exported to text files and subsequently combined with simulation outputs for visualization and comparison. These analytical results are typically stored in the folder *predictions*, using the same parameter combinations and naming conventions as the corresponding simulations to facilitate direct comparison.

Those results are often stored in a folder **predictions** aligning with simulations with the same set of paramters. 

### Simulation framework.

Simulations were performed on the ASC (Austrian Scientific Computing) cluster using the shell script *process.asc.sh*. This script records the command-line calls used to generate all simulation data. The underlying simulation code are stored in the **code** directory (orgnized here in folder **simulation**). Output files were generated under parameter-dependent filenames and stroed in specifed directories. 

For example, allele frequnecy dynamics in single-locus underdominant model were simulated using:

>python3 $code/simUnderDomi.py  --max_generations 500001 --Ns $Ns --Nm $Nm --init_allele_freq $initFrq --outfile $data/frq_$initFrq\_Nm$Nm\_Ns$Ns\_r$r

In this case, simulations track allele frquencies over time for specified combinations of total generations (500001), selection strength (the underdominant coefficient scaled by deme size *N* (*Ns*), the scaled migration rate scaled (*Nm*), and initial allele frequencies defined by variable *initFrq*. Frequencies were typically recorded at fixed intervals (e.g., every 1000 generations).  

For multilocus stabilizing selection with three heterogeneous effects, simulations were run using:

>python3 $code/simStabSel_diffEff.py  --subpopulation_size $N --Nm $Nm --Vs $Vs --num_loci $numLoc --num_generations 100002  --output_file $data/3eff/het_trait_frqB1_Nm$Nm\_Vs$Vs\_N$N\_D100_L$numLoc\_r$r

These simulations output time series of allele frequencies, heterozygosity, trait mean, trait variance (genetic variance), and genic variance (see header of the output file).

### Visualization.

All plotting scripts are located in the **plot** directory and are writen in R. Figures in the manuscript are generated by first computing summary statistics (means and standard errors) from simulation replicates and then plotting these values together with analytical predictions.

A technical note: in several figures, the *x* axis is displayed on logarithmic scale, and its range is manually adjusted using *xlim*. In some cases, parameter values outside the displayed logarithmic range (e.g., *Nm=0*) are still be included in the analysis but are plotted in the additional region of the *x* axis (to the left of the axis break) to provide the complete view of the predictions.
